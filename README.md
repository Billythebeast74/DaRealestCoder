# YardLink

Landscaping marketplace prototype hosted at https://sollyandwill.netlify.app.

## App

Open index.html in a browser. No build or dependencies are required.

Worker dashboard supports viewing sample workers, accepting requests, and completing jobs. Jobs are stored in the current browser only. Accounts, cross-device syncing, payments, satellite measurement, and AR scanning are not implemented.

## Collaboration

Keep changes in this repository. Use a separate branch for each change and review pull requests before merging into main. Connect Netlify production deployment to main, with the repository root as the publish directory and no build command.

Do not store passwords, API keys, or real customer data in the repository.
